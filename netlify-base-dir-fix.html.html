إصلاح مشكلة "Base directory does not exist" في Netlify

دليل خطوة بخطوة لتشخيص وإصلاح أخطاء الدليل الأساسي في Netlify

فهم المشكلة

خطأ "Base directory does not exist: /opt/build" يعني أن Netlify لا يمكنه العثور على الدليل الأساسي المحدد في إعدادات البناء. هذا يحدث عادةً بسبب:

  • تحديد مسار خاطئ للدليل الأساسي في ملف netlify.toml
  • إعدادات خاطئة في لوحة تحكم Netlify
  • الفرع (branch) المحدد لا يحتوي على الدليل المطلوب
  • هيكل مشروع غير متوافق مع إعدادات Netlify
Error: Base directory does not exist: /opt/build

خطوات الحل

1 التحقق من هيكل المشروع

أولاً، تحقق من هيكل المجلدات في مشروعك. يجب أن يتطابق الدليل الأساسي المحدد مع هيكل مجلداتك.

├── my-project/
│ ├── public/
│ │ ├── index.html
│ │ └── favicon.ico
│ ├── src/
│ │ ├── index.js
│ │ └── style.css
│ ├── package.json
│ └── netlify.toml
└── other-folder/
نصيحة

استخدم الأمر tree في terminal لرؤية هيكل مجلدات مشروعك:

# تنزيل الأداة إذا لم تكن مثبتة
sudo apt install tree

# عرض هيكل المجلدات
tree -a

2 التحقق من ملف netlify.toml

تأكد من أن إعدادات الدليل الأساسي في ملف netlify.toml صحيحة وتشير إلى المسار الصحيح.

مثال خاطئ

netlify.toml
[build]
  base = "/opt/build"  # خطأ: هذا المسار غير موجود
  publish = "dist"
  command = "npm run build"

مثال صحيح

netlify.toml
[build]
  base = "/"           # المسار الجذر للمشروع
  publish = "dist"
  command = "npm run build"

# أو إذا كان مشروعك في مجلد فرعي
[build]
  base = "/my-project" # المسار إلى مجلد المشروع
  publish = "dist"
  command = "npm run build"
نصيحة

إذا كان مشروعك في المجلد الجذري، استخدم base = "/" أو احذف سطر base تمامًا.

3 التحقق من إعدادات Netlify

قد تكون المشكلة في الإعدادات التي تم تكوينها في لوحة تحكم Netlify.

  1. تسجيل الدخول إلى Netlify
  2. اختر موقعك من القائمة
  3. اذهب إلى Site settings → Build & deploy
  4. تحقق من إعدادات البناء خاصة:
    • Base directory: تأكد أنه يشير إلى المسار الصحيح
    • Build command: تأكد من أنه صحيح
    • Publish directory: تأكد من أنه صحيح
  5. إذا كنت تستخدم ملف netlify.toml، فتأكد من أن الإعدادات في لوحة التحكم لا تتعارض معه
نصيحة

الإعدادات في ملف netlify.toml تتجاوز الإعدادات في لوحة تحكم Netlify. ننصح باستخدام ملف netlify.tomل لتكون إعداداتك جزءًا من المشروع.

4 التحقق من إعدادات الفرع (Branch)

إذا كنت تستخدم فرعًا معينًا للنشر، تأكد من أن هيكل المجلدات في هذا الفرع يتطابق مع الإعدادات.

netlify.toml مع إعدادات متقدمة للفروع
# الإعدادات العامة
[build]
  publish = "dist"
  command = "npm run build"

# إعدادات خاصة بفرع main
[context.production]
  base = "/"

# إعدادات خاصة بفرع develop
[context.develop]
  base = "/"
  command = "npm run build:dev"

# إعدادات خاصة بفرع feature/*
[context.feature]
  base = "/"

5 اختبار الإعدادات محليًا

اختبر عملية البناء محليًا باستخدام Netlify CLI للتحقق من صحة الإعدادات قبل النشر.

أوامر اختبار Netlify محليًا
# تثبيت Netlify CLI
npm install -g netlify-cli

# الانتقال إلى مجلد المشروع
cd my-project

# محاكاة بناء Netlify
netlify build

# أو لتشغيل موقعك محليًا مع إعدادات Netlify
netlify dev
نصيحة

Netlify CLI سيساعدك على اكتشاف الأخطاء في الإعدادات قبل عملية النشر الفعلية.

إذا استمرت المشكلة

إذا لم تحل الخطوات السابقة المشكلة، جرب ما يلي:

  • تأكد من أن مستودع GitHub يحتوي على جميع الملفات والمجلدات المطلوبة
  • تحقق من أن الفرع المحدد في إعدادات Netlify يحتوي على كود المشروع
  • جرب حذف ذاكرة التخزين المؤقت (Cache) من إعدادات البناء في Netlify
  • انظر إلى سجلات البناء (Build logs) في Netlify للحصول على تفاصيل أكثر عن الخطأ
